![Portfolio Preview](./public/portfolioImg.png)

---

## ✨ Key Features

-   **🌊 Ultra-Smooth Scrolling**: Powered by [Lenis](https://github.com/darkroomengineering/lenis) for a fluid user experience.
-   **🎬 Immersive Animations**: Complex motion sequences using **GSAP** and **Framer Motion**.
-   **📱 Fully Responsive**: Optimized for all devices, from mobile (320px+) to large desktops.
-   **🎨 Premium UI/UX**: Dark mode aesthetic with glassmorphism effects and custom typography (Inter, Sora, JetBrains Mono).
-   **🖱️ Custom Cursor**: Interactive custom cursor that reacts to user input.
-   **📧 Contact Integration**: Functional contact form powered by **EmailJS**.
-   **🔥 Modern Tech Stack**: Utilizing the latest versions of Next.js, React, and Tailwind CSS.

## 🚀 Getting Started

### Prerequisites
-   Node.js 18.x or later
-   npm, yarn, or pnpm

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Ahsanul-Islam-083/ahsanul.islam.git
    ```

2.  **Navigate to the project directory**:
    ```bash
    cd ahsanul.islam
    ```

3.  **Install dependencies**:
    ```bash
    npm install
    ```

4.  **Set up environment variables**:
    Create a `.env.local` file in the root directory and add your EmailJS credentials:
    ```env
    NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
    NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
    NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
    ```

5.  **Run the development server**:
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) to view the result.
